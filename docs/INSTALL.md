# 윈도우 설치 안내

기록 프로그램의 윈도우 설치 파일을 받아 설치하고 쓰는 방법이다. 설치 파일은 [릴리스](https://github.com/jongsu-king/band-heater-pid/releases/latest)에 있다. 버전마다 무엇을 확인했고 무엇을 확인하지 못했는지는 그 릴리스의 설명에 적는다. 화면의 기능은 [README](../README.md#기록-프로그램)에 있다.

[English](INSTALL.en.md)

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | 윈도우 10 또는 11, 64비트. 설치 파일은 x64용이다. ARM 윈도우 11에서는 x64 에뮬레이션으로 설치는 허용되지만 실행해 보지 않았다 |
| 창을 띄우는 구성 요소 | Microsoft Edge WebView2 런타임. 윈도우 11과 업데이트된 윈도우 10에는 이미 있다. 없으면 설치가 끝날 때 안내 창이 뜨고, Microsoft 다운로드 페이지를 열 수 있다 |
| 파이썬 | 필요 없다. 파이썬 3.12와 필요한 패키지가 설치 폴더에 같이 들어 있다 |
| 관리자 권한 | 기본 설치(지금 사용자용)에는 필요 없다. "모든 사용자용"을 고르면 필요하다 |
| 디스크 | 릴리스 설명의 "빌드 정보"에 적힌 설치 폴더 크기만큼. 기록 파일은 따로 문서 폴더에 쌓인다 |
| 보드 연결 | 아두이노 나노의 USB. 장치 관리자의 "포트(COM & LPT)"에 COM 포트로 보여야 한다. 안 보이면 보드의 USB-시리얼 칩(FTDI, CH340 등) 드라이버가 필요하다 |
| 펌웨어 | 이 저장소의 펌웨어. v1.4 이상이면 프로그램 운전이 목표를 `spt`로 바꿔 EEPROM에 쓰지 않는다. 그보다 낮으면 `sp`를 쓰므로 목표를 바꿀 때마다 보드에 저장된다 |
| 인터넷 | 설치와 실행에 필요 없다. 프로그램 코드는 외부 서버에 접속하지 않는다 |

## 설치 순서

설치 화면의 순서는 설치 스크립트(`packaging/windows/installer.iss`)의 설정에서 나오는 것이다. 자동 시험은 화면 없이 하는 조용한 설치로만 했다.

1. 릴리스에서 `Band-Heater-Logger-<버전>-windows-x64-setup.exe`를 받는다. 받은 파일이 맞는지 보려면 아래 "받은 파일 확인"을 따른다.
2. 파일을 두 번 누른다. 코드 서명을 하지 않은 파일이라 "Windows의 PC 보호" 창(SmartScreen)이 뜬다. `추가 정보`를 누른 뒤 `실행`을 누른다.
3. 설치 대상을 묻는다. "지금 사용자용"(권장)은 관리자 권한 없이 설치한다. "모든 사용자용"은 관리자 권한을 요구한다.
4. 사용권 계약(MIT 라이선스)에 동의한다.
5. 설치 폴더를 고른다. 기본값은 지금 사용자용이면 `C:\Users\<사용자>\AppData\Local\Programs\Band Heater PID Logger`, 모든 사용자용이면 `C:\Program Files\Band Heater PID Logger`다.
6. 바탕화면 아이콘을 만들지 고른다. 기본은 만들지 않음이다.
7. `설치`를 누른다. 끝나면 "프로그램 실행"에 표시한 채로 `마침`을 누르면 바로 켜진다.

설치 화면의 언어는 윈도우 표시 언어를 따른다. 한국어 윈도우면 한국어, 그 밖에는 영어다.

## 설치되는 것

| 무엇 | 어디 |
|---|---|
| 프로그램 | 설치 폴더의 `HeaterLog.exe`와 `_internal` 폴더(파이썬 런타임, pywebview, pyserial, 화면 파일 `heater_log.html`, 가상 보드 `sim\sim_bin.exe`). 전체 목록은 `BUILD-INFO.txt` |
| 시작 메뉴 바로 가기 | 한국어로 설치하면 `밴드 히터 PID 기록`, 영어로 설치하면 `Band Heater PID Logger` |
| 바탕화면 바로 가기 | 고른 경우에만, 이름은 위와 같다 |
| 제거 프로그램 | 설치 폴더의 `unins000.exe`. 설정의 앱 목록에 `Band Heater PID Logger`로 보인다 |
| 등록 정보 | 지금 사용자용이면 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\{AED7B226-0390-4D06-9414-BBF97850FE7D}_is1`, 모든 사용자용이면 같은 경로의 `HKLM` |

서비스, 시작 프로그램, 파일 연결, 방화벽 규칙, 드라이버는 설치하지 않는다. 환경 변수도 바꾸지 않는다.

## 처음 실행

1. 프로그램을 먼저 켠다. 포트를 열면 나노가 리셋되기 때문에(아두이노의 정상 동작), 운전 중에 켜면 히터가 꺼진다. 프로그램을 켠 뒤에 운전을 시작한다.
2. 보드를 USB로 연결한다. 프로그램이 포트를 스스로 찾는다. USB 제조사 번호가 FTDI(0403), CH340(1A86), CP210x(10C4), 아두이노(2341, 2A03), Prolific(067B)인 포트를 먼저 고르고, 속도는 115200이다. 포트가 여러 개면 왼쪽 패널의 포트 목록에서 직접 고른다.
3. 연결되면 보드가 1초마다 보내는 값이 그래프와 파일에 쌓인다. 프로그램은 3초마다 `show`를 보내 상태와 설정을 읽는다. `show`는 EEPROM에 쓰지 않는 명령이다.
4. 보드가 없으면 왼쪽 패널의 `연습 모드`를 누른다. 펌웨어를 PC용으로 그대로 컴파일한 가상 보드가 30배속으로 돈다. 실제 히터는 켜지지 않는다. 가상 보드의 온도 곡선은 임의로 정한 열 모델이라 실제 히터의 값이 아니다.
5. 화면 언어는 툴바에서 한국어와 영어 중에 고른다. 처음에는 한국어다.

창은 1280 × 880으로 열리고 1000 × 700보다 작아지지 않는다. 화면은 이 컴퓨터 안의 주소 `127.0.0.1`의 포트 8765(쓰는 중이면 8784까지 차례로)에서만 열린다. 다른 컴퓨터에서는 접속할 수 없고, 명령을 보내는 요청은 실행할 때마다 새로 만드는 토큰이 있어야 받는다. 프로그램이 켜져 있는 동안은 PC가 절전으로 들어가지 않게 한다. 화면이 꺼지는 것은 막지 않는다.

화면의 기능(툴바, 차트, 통계, 응답, 피팅, 모델, 분석, 온도 프로그램, PC 경보, 안정 판정, 기록 목록, 보고서, 설정, 단축키)은 [README의 표](../README.md#기록-프로그램)에 있다.

## 기록 파일

기록은 문서 폴더의 `밴드히터_기록`에 남는다. 문서 폴더의 위치는 윈도우에 물어서 정하므로 OneDrive로 옮겨져 있으면 그쪽에 생긴다. 왼쪽 패널의 `기록 폴더`를 누르면 탐색기로 열린다. 연습 모드의 기록은 그 안의 `연습` 폴더에 따로 남는다.

실험(기록)마다 파일 네 개가 생긴다. 이름은 `heater_날짜_시각_이름`으로 시작한다.

| 파일 | 내용 |
|---|---|
| `.csv` | 1초마다 한 줄. 열은 `time, elapsed_s, PV_degC, SP_degC, OUT_pct, T1_degC, T2_degC, T3_degC, T4_degC, mode` |
| `_events.txt` | 운전, 정지, 경보, 설정 변경, 보낸 명령, 마커 |
| `_raw.log` | 보드가 보낸 줄 전부, 받은 시각과 함께 |
| `_meta.json` | 실험 이름, 시료, 메모, 채널 이름, 펌웨어 버전, 시작할 때의 PID 설정, 열 설명 |

화면에서 저장하면 같은 이름 머리로 `_stats.tsv`(구간 통계), `_part_*.csv`(구간만), `_graph_*.png`(그림), `_report_*.html`(보고서)이 더 생긴다. 프로그램 단계, 경보 한계, 언어 같은 설정은 기록 폴더의 `설정.json`에 남는다. 값이 한 줄도 없고 마커도 없는 기록은 끝낼 때 지운다.

## 제거, 다시 설치, 새 버전

- 제거: 설정 → 앱 → 설치된 앱에서 `Band Heater PID Logger`를 제거한다. 프로그램 폴더와 바로 가기, 등록 정보가 지워진다. **기록 폴더(`밴드히터_기록`)는 지우지 않는다.**
- 다시 설치: 같은 설치 파일을 다시 실행하면 같은 자리에 덮어 설치한다.
- 새 버전: 새 설치 파일을 실행하면 같은 자리에 덮어 설치하도록 만들었다(이전 버전의 `_internal` 폴더를 먼저 비운다). 1.5가 첫 버전이라 버전을 올리는 설치는 아직 시험하지 못했다.
- 자동 업데이트는 없다. 새 버전은 이 저장소의 릴리스에서 받는다.

## 명령줄

설치 파일(조용한 설치). 자동 시험에서 쓴 것은 `/ALLUSERS`를 뺀 전부다.

```bat
Band-Heater-Logger-<버전>-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER
```

| 스위치 | 뜻 |
|---|---|
| `/VERYSILENT` | 화면 없이 설치 |
| `/SUPPRESSMSGBOXES`, `/NORESTART` | 물음 창과 다시 시작을 막음 |
| `/CURRENTUSER` 또는 `/ALLUSERS` | 지금 사용자용 또는 모든 사용자용 |
| `/DIR="경로"` | 설치 폴더 |
| `/LANG=ko` 또는 `/LANG=en` | 설치 언어(바로 가기 이름이 따라 바뀜) |
| `/TASKS=desktopicon` | 바탕화면 아이콘도 만듦 |
| `/LOG="파일"` | 설치 기록을 파일로 남김 |

조용한 제거는 설치 폴더의 `unins000.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`다.

프로그램(`HeaterLog.exe`). 바로 가기의 대상 뒤에 붙여 쓸 수 있다.

| 옵션 | 뜻 |
|---|---|
| `--port COM5` | 포트를 지정(생략하면 자동) |
| `--out "폴더"` | 기록 폴더를 바꿈 |
| `--name "이름"` | 실험 이름을 미리 정함(파일 이름에 붙음) |
| `--lang ko` 또는 `--lang en` | 화면 언어(생략하면 지난번에 고른 것) |
| `--sim 30` | 보드 없이 가상 보드 30배속으로 시작 |
| `--http-port 8765` | 화면용 포트의 시작 번호 |

## 알려진 제한

- 코드 서명이 없다. SmartScreen 경고가 뜨고, 백신에 따라서는 서명 없는 프로그램을 막거나 검사하느라 첫 실행이 느릴 수 있다.
- 알림 센터 알림(안정, 프로그램 종료, 경보, 연결 끊김)은 맥에서만 된다. 윈도우에서는 화면의 표시와 경보음, 이벤트 기록으로만 알린다.
- 자동 업데이트가 없다.
- 온도 프로그램 운전과 PC 경보는 PC와 이 프로그램이 켜져 있을 때만 동작한다. PC나 프로그램이 꺼지면 보드는 마지막 목표를 유지하고, 보호는 펌웨어와 하드웨어(과열 차단, 안전 릴레이, 서모스탯)에만 남는다.
- 펌웨어를 보드에 올리는 도구는 들어 있지 않다. 펌웨어는 아두이노 IDE나 avrdude로 올린다.

## 문제가 생기면

| 증상 | 볼 것 |
|---|---|
| "Windows의 PC 보호" 창이 뜬다 | 서명 없는 파일이라 그렇다. `추가 정보` → `실행` |
| 창이 하얗거나 비어 있다 | WebView2 런타임이 없거나 깨진 경우일 수 있다. Microsoft의 WebView2 페이지에서 Evergreen 런타임을 설치한다 |
| "보드를 찾는 중입니다 (USB를 연결하세요)"에서 멈춘다 | 장치 관리자의 "포트(COM & LPT)"에 보드가 보이는지 본다. 안 보이면 USB-시리얼 드라이버를 설치하거나 케이블을 바꾼다(충전 전용 케이블은 안 된다). 보이면 왼쪽 패널에서 그 COM 포트를 직접 고른다 |
| "다른 프로그램이 사용 중"이라고 나온다 | 아두이노 IDE의 시리얼 모니터나 다른 터미널 프로그램을 닫는다. 이 프로그램을 두 번 켠 경우에도 나온다 |
| 켜자마자 히터가 꺼졌다 | 포트를 열 때 나노가 리셋되는 것이다. 프로그램을 먼저 켜고 운전을 시작한다 |
| `연습 모드` 단추가 없다 | 가상 보드 파일이 없는 빌드다. 릴리스의 설치 파일에는 들어 있다 |
| 기록이 어디 있는지 모르겠다 | 왼쪽 패널의 `기록 폴더`를 누른다. 화면 아래에 지금 쓰는 파일의 경로가 보인다 |

그래도 안 되면 [이슈](https://github.com/jongsu-king/band-heater-pid/issues)에 윈도우 버전, 증상, 기록 폴더의 `_events.txt`와 `_raw.log`를 붙여 올린다.

## 받은 파일 확인

`SHA256SUMS.txt`의 값과 받은 파일의 해시가 같아야 한다. 값은 릴리스 설명의 "받을 파일" 표에도 있다.

```powershell
Get-FileHash .\Band-Heater-Logger-<버전>-windows-x64-setup.exe -Algorithm SHA256
```

```bat
certutil -hashfile Band-Heater-Logger-<버전>-windows-x64-setup.exe SHA256
```

맥이나 리눅스에서는 두 파일을 같은 폴더에 두고 `shasum -a 256 -c SHA256SUMS.txt`를 실행한다.

## 직접 빌드하기

윈도우 PC에서 저장소의 `build_windows.bat`을 실행하면 `dist\`에 프로그램 폴더와 설치 파일이 생긴다.

| 필요한 것 | 용도 |
|---|---|
| [uv](https://docs.astral.sh/uv/) | 파이썬과 PyInstaller, pywebview, pyserial을 받아 빌드한다 |
| g++ (MinGW-w64), 선택 | 연습 모드용 가상 보드를 컴파일한다. 없으면 가상 보드 없이 빌드한다 |
| [Inno Setup 6](https://jrsoftware.org/isinfo.php), 선택 | 설치 파일을 만든다. 없으면 프로그램 폴더까지만 만든다 |

릴리스의 설치 파일은 GitHub Actions의 `Windows installer` 워크플로가 같은 파일을 실행해 만든다. 이 워크플로는 빌드 뒤에 펌웨어 모의 시험, 가상 보드 자동 점검, 조용한 설치와 제거, 한국어 설치를 확인하고, `v<버전>` 태그면 설치 파일과 `SHA256SUMS.txt`, `BUILD-INFO.txt`를 릴리스에 올린다. 릴리스 설명은 `docs/release-notes/<버전>.md`에 쓴 글에 그 빌드의 해시와 도구 버전, 시험 결과를 채워 만든다(`packaging/release_notes.py`).

## 주의

220V를 다룬다. 누전차단기, 퓨즈, 접지, 과열 서모스탯을 빼지 않는다. 배선은 전원을 뽑은 상태에서 한다. 이 프로그램의 경보는 보드와 하드웨어의 보호 기능을 대신하지 않는다. MIT 라이선스로, 보증 없이 제공한다.
